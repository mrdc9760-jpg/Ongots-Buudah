# Онгоцны байлдаан: найзтай тоглох сервер

Энэ багц нь өөрийн вэб сайт болж ажиллана. Хоёр хүн өөр өөрийн утсан дээрээс нэг өрөөнд орж тоглоно. Онгоцны байрлал серверт хадгалагдаж, буудалт бүрийг сервер шийддэг тул хуурч болохгүй.

## Багцад юу байна

| Файл | Үүрэг |
| --- | --- |
| `server.js`, `game.js` | Сервер: өрөө, дүрэм, буудалт, дахин холбогдох. Нэмэлт сан суулгах шаардлагагүй. |
| `public/` | Тоглоомын хуудас (`index.html`, `style.css`, `app.js`, `logic.js`, `draw.js`). |
| `package.json` | `npm start` командыг тодорхойлно. Node.js 18-аас дээш хувилбар хэрэгтэй. |
| `test_server.js` | Серверийн автомат тест (`npm test`). |

## 1. Өөрийн компьютер дээр туршиж үзэх (заавал биш)

1. Node.js 18 буюу түүнээс дээш хувилбарыг nodejs.org-оос суулгана.
2. Багцыг задалж, тэр хавтсанд `node server.js` гэж ажиллуулна.
3. Хөтөч дээр `http://localhost:3000` нээнэ. Хоёр дахь тоглогчоор тусдаа нууц цонх (private window) нээж болно.

## 2. GitHub дээр хадгалах

Render нь кодыг GitHub-аас авдаг. Компьютер ашиглавал хамгийн хялбар.

1. github.com дээр бүртгэл үүсгэнэ (**Sign up**).
2. Баруун дээд буланд **+** → **New repository** дарна. Нэр: `onggoc-baylaldaan`. **Private** эсвэл **Public** сонгоод **Create repository** дарна.
3. Zip файлыг задална.
4. Шинэ repository хуудсан дээрх **uploading an existing file** холбоосыг дарна.
5. Задалсан хавтсан доторх бүх зүйлийг (`server.js`, `game.js`, `package.json`, `test_server.js`, `.gitignore`, `README.md` болон **`public` хавтсыг бүхэлд нь**) хөтчийн цонх руу чирч оруулна.
6. `public` хавтас дотор 5 файл хавтасныхаа бүтэцтэйгээр орсон эсэхийг шалгана. Зөв бол файлын жагсаалтад `public/index.html` гэж харагдана.
7. Доор **Commit changes** дарна.

## 3. Render дээр байрлуулах

1. render.com руу орж **Get Started** дараад GitHub-ээр нэвтэрнэ.
2. **New** → **Web Service** дарна. `onggoc-baylaldaan` repository-гоо сонгоно. Хэрвээ жагсаалтад харагдахгүй бол Render-д GitHub дээрх repository-д хандах эрх өгөх хэрэгтэй.
3. Талбаруудыг ингэж бөглөнө:
   - **Name:** дурын нэр. Энэ нь холбоосонд орно (жишээ нь `onggoc-baylaldaan`).
   - **Language:** `Node`
   - **Branch:** `main`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
4. **Create Web Service** дарна. Байрлуулах явц **Logs** хэсэгт харагдана. «Онгоцны байлдаан: http://localhost:…» гэсэн мөр гарвал бэлэн боллоо.
5. Хуудасны дээд талд `https://таны-нэр.onrender.com` гэсэн холбоос гарна. Энэ нь таны тоглоомын хаяг.
6. (Заавал биш) **Settings** → **Health Check Path** хэсэгт `/healthz` гэж бичнэ.

## 4. Найзтайгаа тоглох

1. Хоёулаа тэр холбоосыг утсан дээрээ нээнэ. Анх нээхэд ойролцоогоор 1 минут хүлээх хэрэгтэй байж болно (доорх «Үнэгүй төлөвлөгөөний хязгаар»).
2. Нэг тоглогч «Найзтай тоглох» → «Өрөө үүсгэх» дарна. Онгоцны тоо, устах дүрмийг өмнө нь сонгоно.
3. «Урилга илгээх» дараад холбоосыг найздаа илгээнэ. Эсвэл 4 тэмдэгттэй кодыг хэлнэ.
4. Найз нь холбоосоор орж «Өрөөнд орох» дарна.
5. Хоёулаа онгоцоо байрлуулаад «Бэлэн» дарна. Хоёулаа бэлэн болмогц тулалдаан эхэлнэ. Хэн түрүүлж буудахыг сервер санамсаргүй сонгоно.
6. Дуусахад «Дахин тоглох» хоёулаа дарвал шинэ тоглолт эхэлнэ.

Хуудсаа дахин ачаалсан эсвэл утас түр унтарсан ч тоглолтод буцаж орно (сервер ажиллаж байвал).

## 5. Үнэгүй төлөвлөгөөний хязгаар (Render, 2026 оны 10-р сарын мэдээллээр)

- Үнэгүй сервер 15 минут HTTP хүсэлтгүй байвал унтдаг. Дараагийн нээлт ойролцоогоор 1 минут үргэлжилнэ. Өрөөнд байх үед тоглоом 4 минут тутам өөрөө хүсэлт илгээж сервер унтахаас сэргийлнэ.
- Сервер унтах, дахин асах, шинэ хувилбар тавих үед бүх өрөө устна. Тэгвэл тоглолт тасарч, шинэ өрөө үүсгэх хэрэгтэй.
- Сард 750 үнэгүй цаг байдаг. Онлайн байх үед л цаг зарцуулагдана.
- Үргэлж сэрүүн байлгах бол төлбөртэй төлөвлөгөө (жишээ нь сард $7 орчим, 0.5 CPU, 512 MB) руу шилжүүлнэ. Үнэ өөрчлөгдөж болох тул render.com/pricing хуудсыг шалгана уу.
- Railway зэрэг өөр үйлчилгээ ашиглаж болно. Байнгын үнэгүй төлөвлөгөө байхгүй, нэг удаагийн кредиттэй гэж үзсэн. Бүртгүүлэхээсээ өмнө одоогийн нөхцөлийг шалгана уу.

## 6. Асуудал гарвал

| Асуудал | Шийдэл |
| --- | --- |
| «Өрөө олдсонгүй» гэж гарав | Сервер унтсан эсвэл дахин асаж өрөө устсан байж болно. Шинэ өрөө үүсгэнэ. Кодыг зөв бичсэн эсэхийг шалга. |
| Хуудас олон секунд ачаалж байна | Үнэгүй сервер унтсан байсан. Нэг минут хүлээнэ. |
| Deploy амжилтгүй болов | **Logs** дахь алдааг үзнэ. `public` хавтас, `package.json` repository-н язгуур түвшинд байгаа эсэхийг шалгана. |
| Сүлжээ шууд холбогдохгүй (сургууль, оффисын сүлжээ) | Хуудас автоматаар 1.5 секунд тутам асуудаг хувилбар руу шилждэг. Бага зэрэг удаан хариулна. |
| Зураг орохгүй | Зураг 25 МБ-аас бага байх ёстой. Өөр зураг сонгоно уу. |

## 7. Шинэчлэх

GitHub дээрх файлаа сольвол Render автоматаар шинэ хувилбар байрлуулна. Энэ үед идэвхтэй өрөөнүүд устахыг анхаарна уу.

## 8. Нууцлал, аюулгүй байдал

- Өгөгдлийн сан байхгүй. Нэр, зураг, онгоцны байрлал серверийн санах ойд зөвхөн өрөө байх хугацаанд хадгалагдана. Өрөө 1 цаг үйлдэлгүй байвал (хүлээж буй өрөө 30 минут) автоматаар устна.
- Оноо, зэрэг, хожил хожигдол нь тоглогч бүрийн өөрийн утсан дээр хадгалагдана. Сервер дээр хадгалагдахгүй.
- Нэг хаягаас 10 минутанд 20 өрөө үүсгэх, 40 өрөөнд орох оролдлогын хязгаартай. Серверт 300 өрөө хүртэл байж болно.
- Нууц үг, түлхүүр шаардахгүй.
